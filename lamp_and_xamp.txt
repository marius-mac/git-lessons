-----------------------------------------------------------

Managing Both Services

LAMP: Controlled via systemctl: 
sudo systemctl start apache2

XAMPP: Controlled via /opt/lampp/lampp:
sudo /opt/lampp/lampp start

GUI Control: You can launch the XAMPP manager GUI with: 
sudo /opt/lampp/manager-linux-x64.run

-----------------------------------------------------------

You can check which Apache is active by checking the version in the terminal

LAMP:
apache2 -v

XAMPP:
/opt/lampp/bin/apachectl -v
